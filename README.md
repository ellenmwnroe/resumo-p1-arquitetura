# Resumo P1 · Arquitetura e Organização de Computadores

Página interativa de revisão para a P1, feita pela monitora **Ellen Monroe**.

- Resumo de todos os assuntos: gerações, binário, portas lógicas, desempenho (pipeline e superescalar), hierarquia de memória, CISC × RISC, circuitos e barramentos
- Simuladores: bits → decimal, portas AND/OR/NOT com circuito equivalente, pipeline ciclo a ciclo, largura de barramento
- 38 perguntas com correção na hora, dica, segunda chance e resultado por assunto
